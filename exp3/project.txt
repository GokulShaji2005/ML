Important Distinction: Regularization vs Classification Threshold

We initially had L1 and L2 logistic regression models in the code and were confused about whether the threshold should replace L1/L2.

We now understand that these are different concepts.

L1/L2 regularization

L1 and L2 affect the training process and model coefficients.

L1 adds a penalty based on the absolute coefficient values.

L2 adds a penalty based on squared coefficient values.

L1 can make coefficients exactly zero.

L2 generally shrinks coefficients without making them exactly zero.

These are not the classification thresholds we are investigating.

Classification threshold

Logistic regression produces a probability for class 1:

y_prob = model.predict_proba(X_test)[:, 1]


A classification threshold converts that probability into a class prediction.

For example:

y_pred = (y_prob >= 0.5).astype(int)


means:

Probability >= 0.5 → Class 1
Probability < 0.5  → Class 0


The default predict() behaviour effectively uses the 0.5 decision threshold for binary logistic regression, but we want to explicitly control the threshold for our experiment.

What We Need to Understand

We suspect this happens because the model's predicted probabilities may be concentrated mostly near 0 and 1.

For example, if the model predicts probabilities such as:

0.001
0.003
0.02
...
0.97
0.99
0.999


then thresholds of 0.3, 0.4, 0.5, 0.6 and 0.7 may all produce the exact same classifications.

However, we do not want to assume this without examining the actual probabilities.

We therefore want to inspect:

print("Minimum:", np.min(y_prob))
print("Maximum:", np.max(y_prob))
print("Mean:", np.mean(y_prob))
print(np.sort(y_prob))


We can also inspect probabilities close to the threshold region:

near_threshold = y_prob[
    (y_prob >= 0.1) &
    (y_prob <= 0.9)
]

print(np.sort(near_threshold))


Another useful check is to find probabilities closest to 0.5:

closest = np.argsort(np.abs(y_prob - 0.5))[:20]

print(y_prob[closest])

Main Goal

Instead, we want to:

Select meaningful threshold values that demonstrate changes in predictions, if possible.

Compare FP, FN, precision, recall and F1-score across thresholds.

Explain the trade-off clearly.

Produce suitable tables and graphs for the project report.

Avoid confusing classification threshold with L1/L2 regularization.

The central concept we need to demonstrate is:

        ↓

        ↓
